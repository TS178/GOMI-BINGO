# 海ゴミBINGO！

GitHubへの登録・配布用フォルダーです。2026年10月16日時点のアプリを収録しています。

## 使用方法

このフォルダーの**中身すべて**をリポジトリのルートへ入れてください。`index.html`と`assets/`・`fonts/`を同じ階層に保ってください。

```text
index.html
ui.css
opening.css
opening.js
image-cache.js
tile-icons.js
logo-assets.js
game-effects.js
quiz-visuals.js
player-profile.js
assets/
  badges/
  categories/
  logo/
  photos/
  quiz/
fonts/
  NotoSansJP-App.woff2
  NotoSansJP-Variable.woff2
  OFL.txt
.gitignore
README.md
```

`index.html`をブラウザーで開くと起動します。ビルドやパッケージのインストールは不要です。

ごみずかんには、指定HTMLから取り出した実写写真8点（`assets/photos/`）を使用しています。ビンゴ盤面・問題・解説のイラストもすべて同梱しています。

画像・フォントを軽量化し、配布ファイル全体は約12.5MBです（旧版：約157MB／150MiB）。確認用スクリーンショットや開発用テストは含めていません。

画像77点はWebP形式です。ジャンル画像は最大640px、問題・解説・実写写真は最大960pxに調整し、ロゴは元の解像度のまま可逆圧縮しています。ごみずかんの写真は元の実写写真を縮小したものです。

HTMLの未使用の埋め込み画像を除去し、約6.46MBから約62KBに軽量化しました。フォントは通常画面で使う文字を小さなファイルから読み込み、その他の漢字を含む名前には完全版を必要時に読み込みます。フォントの読み込み完了を待たずにオープニングを開始します。開始に必要なデータは約0.8MBです（入力した名前によって追加フォントの読み込みがあります）。

オープニングの表示後、ジャンル・実写写真・クイズ・解説・バッジ68点（約7.3MB）をバックグラウンドで先読みします。同時取得は2点まで、描画用に保持する画像は12点までです。ごみずかんを開くと関連する問題を、問題を表示するとその解説と次の問題を優先して読み込みます。回線が遅く先読みが間に合わなくても、先読み完了のために画面操作を待たせることはありません。

クイズの画像枠・文字サイズ・行間・選択肢を画面サイズに応じて調整し、画像を大きく表示しながら1画面に収まるようにしています。画像全体を表示し、問題の意味に関わる部分を切り抜かない構成です。

名前と進行状況は各利用者のブラウザーへ保存され、配布ファイルには書き込まれません。異なる端末・URLでは保存内容が共有されません。

フォントはNoto Sans JPです。配布時には`fonts/OFL.txt`も含めてください。
